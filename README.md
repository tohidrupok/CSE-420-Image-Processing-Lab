## 🚀 How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/tohidrupok/CSE-420-Image-Processing-Lab.git
```

### 2. Open MATLAB

Open MATLAB and set the repository directory as your **Current Folder**.

### 3. Select a Lab

Navigate to the required lab session folder.

For example:

```text
Lab Session 01/
```

### 4. Open the MATLAB File

Open the corresponding `.m` file in the MATLAB Editor.

### 5. Run the Script

Click **Run** or execute the script from the MATLAB Command Window.

> **Note:** Some experiments may require input images or additional files. Make sure the required files are available in the appropriate lab directory.
